# DespachoGT + ProtocoloGT

Canal oficial de distribución de instaladores y actualizaciones.

**Todavía no hay versiones publicadas en este repositorio.** Sólo se incorporarán paquetes verificados. Este repositorio no sustituye las copias privadas de documentos ni almacena información de abogados o clientes.

- Los documentos, las credenciales y las claves privadas nunca se incluyen en las descargas.
- El repositorio de desarrollo permanece privado. Los archivos de ejecución incluidos en un programa distribuido pueden ser inspeccionados; no se publica aquí el proyecto de desarrollo completo.
- Microsoft Word y su licencia no están incluidos.
- La aplicación debe verificar la firma, el tamaño y la huella del paquete antes de una actualización; una descarga por sí sola no autoriza su instalación.
